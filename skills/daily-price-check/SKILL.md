---
name: daily-price-check
description: Check a product's price once a day and report only when it changes
---
1. Start a Chore titled "Daily price check: <product>".
2. Find the product page and read today's price, with its source.
3. Schedule a wake-up for the same time tomorrow to read it again, noting today's price in it.
4. Message the user only when the price changes, with the old and new price and the source.
